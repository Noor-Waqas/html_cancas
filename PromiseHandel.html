Api Handle Useing Asign And Await

Promise In JavaScript

Promise handle are three stage

Panding : Initial state neither fulfilled nor rejected.

Fulfilled : Operation was completed successfully.

Rejected : Operation failed

async function getAllUser()
{
try
{
const ApiResponsive = await fetch("https://jsonplaceholder.typicode.com/photos")
const data = await ApiResponsive.json()
console.log(data);
} catch (error)
{
console.log(error);
}
}
